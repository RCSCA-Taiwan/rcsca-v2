# 全站架構與交付順序

更新：2026-10-19（台灣）。依協會最新決定，先完成網站架構及主要流程，名冊、文案、素材和細部規則後補。正式名冊暫不上傳，不阻擋架構工作。

## 主要世界與流程

| 區域 | 主要入口 | 流程骨架 |
| --- | --- | --- |
| 品牌與公開資訊 | `/`、`/about`、`/cycle-of-goodness` | 開場 → 認識理念 → 選擇個人、企業、關懷或連結 |
| 個人與會籍 | `/account`、`/my-1percent`、`/membership/apply` | 註冊驗證 → 入會／續會或歷史認領 → 審核 → 身分、年資、積分與紀錄 |
| 關懷與活動 | `/care-actions` | 活動／需求 → 登記或提出需求 → 核實與處理 → 本人進度及授權公開成果 |
| 企業與 ESG | `/1percent-partner` | 合作申請 → 供應或專案需求 → 審核 → 履約 → 共享成果 |
| 專業與人才 | `/1percent-network`、`/member-network` | 公開專業目錄 → 提出需求／工作／人才 → 意願回應 → 同意媒合與進度 |
| 共享所與交流 | `/share-market`、`/community` | 方案／討論 → 權限確認 → 兌換履約或內容審核 → 紀錄、取消或檢舉 |
| 管理營運 | `/admin/queue`、`/admin/operations` | 查看待辦 → 六類工作區 → 角色允許的處理 → 通知與稽核 |

`/guide` 是跨區功能入口；`/admin/operations#workspaces` 是完整後台總覽。現有 `/admin` 仍導向待辦頁。子頁的「目前位置」連回對應區域，管理員中心連回完整總覽。

## 本批架構補齊

- 補齊活動參與、需求、公開成果、生活服務、工作、人才、媒合進度及規則等功能指南入口。
- 後台依會員、關懷、企業與媒合、共享所與貢獻、交流與小隊、權限與營運整理；保留所有既有操作路徑。
- 待辦頁上方直接連至完整工作區、稽核紀錄與功能指南。
- 共用頁面名稱，補齊所有現有靜態頁及三類動態頁的位置導覽。
- 更新資料準備頁，避免仍把已實作的企業供應、履約與交流功能標示為尚未建置。

## 後續階段

申請後的銜接：`/account/requests` 除需求清單外，提供十個既有流程的追蹤／補件／結果入口，涵蓋會籍與認領、企業註冊與案件、媒合、活動核實、兌換、資料異動、通知及已核實足跡。這些入口不依賴需求清單讀取成功，也不代表每個狀態都可以修改。關懷需求及生活媒合表單直接連回此頁；未登入時保留登入後的目的地。

1. 架構及操作銜接：以現有路由、角色、申請／審核／結果／回到入口的流程為驗收對象。
2. 資料及內容補齊：會員名冊、活動、企業供應、案例、圖片、介紹來源及公開同意，依需要逐批提供。
3. 正式營運驗收：正式備份與異地保存、實機操作、核定積分／貢獻規則及必要帳務設定。

目前已存在註冊、會籍、活動、企業、媒合、兌換履約、交流、通知與後台的實作。入口完整不能代替真實資料或正式營運驗收。未核定的回饋比例、徽章門檻及第三方定期扣款不自行開通；空資料保持真實空狀態。
