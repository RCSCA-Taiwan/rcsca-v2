建議技術架構

前端｜Next.js同一套程式處理公開網站、MY 1%、企業 Dashboard 與後台；RWD 手機優先。
主機｜Vercel先用託管部署，減少自己維護伺服器的成本與風險。
資料庫｜PostgreSQL / Supabase會員、企業、小隊、活動、點數、個案與權限關聯資料放主資料庫。
登入｜Supabase Auth第一版以手機 OTP 為目標；正式環境需配置 SMS provider，並搭配 rate limit 與 CAPTCHA。
權限｜Row Level Security不是「把頁面藏起來」，而是資料庫層就限制誰能讀、寫哪些資料。
防機器人｜Cloudflare Turnstile保護註冊、登入、提出需求、企業申請等表單，減少大量假帳號與濫用。
圖片／影片｜物件儲存第一版少量素材可先用既有儲存；大量會員媒體後續再切 Cloudflare R2 等物件儲存。
網域／DNS｜Cloudflare網域 DNS、安全與未來 CDN 統一管理；不必一開始做複雜企業方案。
