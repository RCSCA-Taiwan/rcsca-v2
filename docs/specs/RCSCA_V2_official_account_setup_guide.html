建立時的硬規則

協會是 Owner，廠商是受邀者未來換執行公司，只撤權，不必把網站討回來。
至少兩位可信任的最高管理者避免單一帳號失聯造成整套系統失控。
最高權限全部開 MFARecovery Code 另存安全位置，不放 LINE 群。
API Key 視同密碼只放 Secrets／環境變數，不貼聊天群與文件。
先不買高階方案、不大量充值 SMS先完成 V1 與封閉測試，再依實際量升級。
STOP POINT

真正建立外部帳號前，先確認協會的數位資產管理 Email。

從下一步開始會產生外部登入憑證與可能的付款關係，所以應一個一個建立，不要一次全部申請。
